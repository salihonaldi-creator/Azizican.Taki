# Azizican Takı – Web Sitesi

El yapımı taş ve cam boncuk bileklikler için tek sayfalık statik vitrin sitesi.

- `index.html`: site
- `images/`: ürün görselleri. Şu anki görseller geçici örneklerdir, yayından önce kendi ürün fotoğraflarınızla aynı adları kullanarak değiştirin.

Yayınlamak için `index.html` ve `images/` klasörünü hostinginizin `public_html` klasörüne yükleyin.
